# Лабораторная работа № 5. Хеш-функции и хеш-таблицы

**Цель** — изучить способы разрешения коллизий и применить хеширование к задачам с блоками, массивами и строками.

## Задачи и решения

| № | Задача | Решение |
|---|---|---|
| 1 | Вставка, поиск и удаление по ключу | Ключи с одинаковым индексом хранятся в одном списке. |
| 2 | Те же операции в таблице с открытой адресацией | При коллизии проверяются соседние ячейки. Метка удаления позволяет продолжить поиск. |
| 3 | Проверить целостность цепочки блоков | Для каждого блока проверяются хеш его содержимого и ссылка на предыдущий блок. |
| 4 | Найти хотя бы один общий элемент двух массивов | Элементы первого массива заносятся в множество, затем в нём ищутся элементы второго. |
| 5 | Проверить уникальность элементов массива | Повтор обнаруживается, когда очередной элемент уже есть в множестве. |
| 6 | Найти пары чисел с заданной суммой | Для числа `x` среди просмотренных значений ищется `сумма - x`. Каждая пара выводится один раз. |
| 7 | Проверить две строки на анаграмму | Сравниваются длины строк и частоты символов с учётом регистра и пробелов. |

## Вывод

Обе таблицы сохранили ключ `9` после удаления ключа `1` с тем же начальным индексом. Проверка блокчейна обнаружила изменение записи. В задачах 4–7 множества и словарь позволили обработать входные данные в среднем за O(n).
