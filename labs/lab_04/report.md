# Лабораторная работа № 4. Стек, очередь, дек

**Цель:** изучить стек, очередь и дек и использовать стек для решения задач.

## Задания и решение

1. Реализовать каждую структуру на массиве и связном списке.
   Созданы базовые классы `Stack`, `Queue`, `Deque` и шесть наследников.
   Базовые классы перечисляют методы, а наследники выполняют операции.
   Массив представлен Python `list`. Связные реализации используют собственные
   узлы: стек и очередь — односвязные, дек — двусвязные.
   У стека добавление и удаление происходят с одного конца, у очереди —
   с разных, у дека доступны оба конца. Просмотр не удаляет элемент.
   Если структура пуста, просмотр и удаление возвращают `None`.
2. Проверить правильность скобочной последовательности из `()[]{}`.
   Открывающие скобки помещаются в стек. Закрывающая должна соответствовать
   верхней скобке стека. После обработки стек должен быть пуст.
   Результат хранится в логической переменной `correct` и возвращается функцией.
   При ошибке выводится сообщение. Пустая строка считается правильной.
3. Вычислить постфиксное выражение. Цифры помещаются в стек. При операции
   извлекаются правый и левый аргументы, результат возвращается в стек.
   В конце проверяется, что остался один результат.
4. Перевести инфиксное выражение в постфиксное. Цифры сразу записываются
   в результат. Операторы хранятся в стеке и извлекаются с учётом приоритета
   и скобок. Операции одинакового приоритета выполняются слева направо.

В заданиях 3 и 4 предполагается корректное выражение: отдельные цифры `1–9`,
бинарные операции `+`, `-`, `*`, `/` и пробелы. В задании 4 разрешены круглые
скобки. Деление обычное; деления на ноль во входных данных быть не должно.
Многозначные числа и унарный минус не поддерживаются. Полная проверка
синтаксиса выражений не выполняется.

## Вывод

Стек работает по правилу LIFO, очередь — FIFO, дек позволяет работать с обоих
концов. На связных узлах основные операции занимают O(1). На массиве работа
с концом занимает амортизированно O(1), с началом — O(n) из-за сдвига элементов.
Просмотр и проверка пустоты занимают O(1). Алгоритмы со стеком требуют O(n)
времени и до O(n) дополнительной памяти, если считать арифметику операцией O(1).
